### Como eu evoluiria daqui

A estrutura que criei é o **MVP visual/funcional local**. Ainda não há backend: os dados exibidos são demonstrativos e o botão do assessment simula o registro.

Na próxima evolução, eu transformaria isso em uma aplicação única com dois perfis:

**QA → Quick Scan → desafio → submissão → avaliação assistida por IA**

**Líder NTT → Dashboard → Gerência → Coordenação → QA → Scan x Quick Scan → evidências → recomendação → decisão do gestor**

E adicionaria uma terceira dimensão muito importante para os **2 Accelerates**:

**Coordenação → Squad → Stack → Regressivo → % automatizado → gaps → massa → pipeline → oportunidades de IA → backlog de aceleração → habilitação.**

Isso conecta os dois trabalhos paralelos que você descreveu: enquanto o **Líder faz Foto + Quick Scan + análise de pessoas**, os **2 Accelerates fazem diagnóstico técnico e constroem o plano de aceleração**. A proposta já prevê para esse time atividades de priorização, regressivo, massas, scripts, pipeline e habilitação. NTT DATA - Proposta Técnica e C…

Eu faria essa próxima versão já como um **mini sistema de gestão do projeto**, em vez de continuar criando páginas isoladas.
